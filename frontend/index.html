🤖 Autonomous GenAI Email Classification & Routing Engine

Self-hosted · running in production for my own inbox
View repo ↗
n8n (Docker)Ubuntu Server Google Gemini APIMicrosoft Graph APIJavaScript
2,000+emails classified & routed
−98%LLM API calls via batch aggregation
~2.4 sper email, end to end
4Architecture Decision Records
  • Orchestrator-Worker architecture — decoupled pagination from processing to avoid Node.js V8 memory leaks in long loops.
  • N-to-1 aggregation — a custom JS layer packs each 50-email batch into one structured payload, so a batch needs a single Gemini inference call instead of 50.
  • 3-tier fault tolerance — transient-failure retries, item-level poison-pill isolation with a local dead-letter log, and an out-of-band catastrophic handler with zero circular dependencies.
  • Every decision documented as ADRs in the repo README, including how each part maps to native AWS services (Step Functions, Lambda, SQS, Bedrock).
