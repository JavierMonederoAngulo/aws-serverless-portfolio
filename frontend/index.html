🤖 Autonomous GenAI Email Classification & Routing Engine

Self-hosted · tested & running on my own Outlook inbox
View repo ↗

2,000+legacy emails processed in initial run
−98%LLM API calls (50-to-1 batching)
~2.4 savg per email (incl. 1s rate-limit delay)
4Architecture Decision Records (ADRs)
  • Orchestrator-Worker decoupling (ADR 01) — separated pagination state from batch execution so child sub-workflows release memory after each batch, avoiding Node.js V8 heap crashes.
  • N-to-1 payload aggregation (ADR 02) — consolidates 50 emails into a single structured JSON prompt per batch, cutting 50 individual LLM calls down to 1 and respecting Gemini RPM quotas.
  • Dual-ingestion & stateless runtime (ADR 03 & 04) — a unified worker handles both bulk legacy batches and single real-time Outlook triggers, dynamically mapping Graph Folder IDs at runtime without fragile global cache state.
  • 3-tier fault tolerance — automatic retries on transient HTTP failures, item-level poison-pill isolation to a local Dead-Letter file (/tmp/n8n_errores_correos.txt), and an out-of-band catastrophic error logger avoiding circular email alerts.
